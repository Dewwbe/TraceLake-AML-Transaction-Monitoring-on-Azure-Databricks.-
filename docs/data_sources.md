# Data sources and licences

Nothing in this repository downloads or redistributes third-party data by default. The local run uses data generated by `scripts/generate_sample_data.py`.

| Source | Use in project | Licence / terms | Verification status |
|---|---|---|---|
| SAML-D (Kaggle, `berkanoztas/synthetic-transaction-monitoring-dataset-aml`) | Default transaction profile (`config/sources/saml_d.yml`) | **Not verified.** Check the Kaggle dataset page before use or redistribution | About 9.5M transactions, 12 features, 28 typologies per the dataset page. Column names and value labels in this repo are recalled, not verified |
| IBM AMLworld (Kaggle) | Alternative transaction source | Community Data License Agreement (per dataset page) | Adapter **not implemented** (no country fields; duplicate `Account` header needs positional handling) |
| OFAC SDN and Consolidated lists | Sanctions list (`aml.ingestion.ofac`) | US Government publication; confirm terms on the Treasury site | Formats (XML, CSV, fixed-field, delta) confirmed from documentation; **download URLs and legacy column order not verified** |
| OpenSanctions bulk data | Optional | CC BY-NC 4.0: **non-commercial only; compliance screening counts as commercial use** | Use only for genuinely non-commercial purposes |
| FATF lists | Country risk table | Check FATF terms | Lists change periodically; **current list not retrieved**; populate `config/country_risk_template.csv` yourself |
| Basel AML Index | Optional country risk input | Not verified | 2025 public edition covers 177 jurisdictions; download and licence terms not verified |
| UN, EU, UAE national lists | Not implemented | Not verified | Formats not verified |

Synthetic components in this repository: transactions, customers, accounts, the sample sanctions list (**fictional**; names are random combinations, resemblance to real persons is coincidental), and the demo country-risk table.

## Verification checklist before using real data

1. Download SAML-D, compare `source_columns`, date format and currency/country labels with `config/sources/saml_d.yml`; extend `currency_aliases` as needed.
2. Confirm the dataset licence permits your intended use (including a public portfolio).
3. Confirm OFAC URLs and compare `aml.ingestion.ofac` column order to the specification file in the download.
4. Build the country-risk table from the current FATF lists using country names matching the transaction source.
